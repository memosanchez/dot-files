## Bash paths

Bash already runs in the session working directory: pass every file and directory argument as an absolute path instead of prefixing a `cd`. Search subtrees such as `apps`, `packages`, or `.github`, never the repo root: the Read deny rules in settings.json cover `.env` files at the root, and a grep, rg, or git grep over a directory that contains them prompts for manual approval regardless of `--include` or `-g` filters. A relative path after a `cd` cannot be resolved by the classifier and prompts too. Explore and Plan subagents never load this file, so restate both rules in the prompt of any subagent that will run shell searches.
